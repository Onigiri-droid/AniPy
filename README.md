🐍 Python-версия (Telegram-бот на Python)
Telegram-бот, уведомляющий пользователей о выходе новых серий аниме.
Использует API Shikimori для получения данных и хранит подписки в JSON-файле. Подходит для небольшого количества пользователей.

🧩 Функционал:</br>
• Подписка/отписка на аниме через кнопки
• Периодическая проверка новых серий
• Отправка уведомлений пользователям
• Кэширование данных из API
⚙️ Используемые технологии:
• Python 3.10+
• python-telegram-bot
• Shikimori API
• APScheduler
• JSON (для хранения данных)
