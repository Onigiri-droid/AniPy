🐍 Python-версия (Telegram-бот на Python)</br>
Telegram-бот, уведомляющий пользователей о выходе новых серий аниме.</br>
Использует API Shikimori для получения данных и хранит подписки в JSON-файле. Подходит для небольшого количества пользователей.</br>

🧩 Функционал:</br>
• Подписка/отписка на аниме через кнопки</br>
• Периодическая проверка новых серий</br>
• Отправка уведомлений пользователям</br>
• Кэширование данных из API</br>
⚙️ Используемые технологии:</br>
• Python 3.10+</br>
• python-telegram-bot</br>
• Shikimori API</br>
• APScheduler</br>
• JSON (для хранения данных)
